Exercise 2: The Trailing Comma
Basics & Indexing

Practice Problem: Create a single-element tuple containing the integer 42. Verify its type is tuple rather than int.

Highlights Python's syntax requirement of a trailing comma for single-element tuples.
Given Input
Value 42
Expected Output
Value: (42,), Type: <class 'tuple'>
Writing (42) evaluates as an integer inside parentheses; you must write (42,).
Python 3
# Without comma -> treated as parenthesized expression:
not_a_tuple = (42)
print("Type of (42):", type(not_a_tuple))  # 

# With trailing comma -> defines a tuple:
single_tuple = (42,)
print("Value:", single_tuple, "Type:", type(single_tuple))
Key Concept: In Python, it is the comma that creates a tuple, not the parentheses. A single item requires (x,).

Exercise 27: The “Modification” Hack
Advanced & Internals

Practice Problem: Change the second element of the tuple ("Python", 3.8, "Released") to 3.12 by temporarily converting it to a list.

Learn how developers bypass immutability via list conversion and re-casting.
Given Input
("Python", 3.8, "Released")
Expected Output
('Python', 3.12, 'Released')
Convert with temp = list(t), modify temp[1] = 3.12, then re-cast: t = tuple(temp).
Python 3
t = ("Python", 3.8, "Released")

# Step 1: Cast to mutable list
temp = list(t)

# Step 2: Modify in place
temp[1] = 3.12

# Step 3: Re-cast to immutable tuple
t = tuple(temp)

print("Updated tuple:", t)
Key Concept: You cannot modify a tuple in place (t[1] = 3.12 raises TypeError). Casting to list creates a brand new tuple reference.

Exercise 32: The Hashability Paradox
Advanced & Internals

Practice Problem: Demonstrate why a tuple containing only integers is hashable (works in set or hash()), but a tuple containing a nested list triggers a TypeError.

Deep-dive into recursive hashability requirements in Python.
Given Input
t1 = (1, 2), t2 = (1, [2])
Expected Output
hash(t1): Success
hash(t2): TypeError: unhashable type: 'list'
Wrap hash(t2) inside a try-except TypeError: block.
Python 3
t1 = (1, 2)
print("t1 hash:", hash(t1))  # Works!

t2 = (1, [2])
try:
    print("t2 hash:", hash(t2))
except TypeError as e:
    print("t2 error:", e)
Key Concept: A tuple is only hashable if every element inside it is also hashable. A nested list renders the entire tuple unhashable.
