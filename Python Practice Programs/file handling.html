Exercise 24: Copy File Using Binary Mode
Basic I/O & Modes

Practice Problem: Write a chunk-based copy routine in binary mode ("rb" / "wb") to duplicate a file efficiently without reading the whole file into RAM at once.

Teaches chunked binary streaming (buffer_size = 64KB) for copying large files.
Given Input
Copy source.bin to dest.bin
Expected Output
Binary copy complete
Loop with while chunk := src.read(64 * 1024): dst.write(chunk).
Python 3
CHUNK_SIZE = 64 * 1024  # 64 KB

with open("source.bin", "rb") as src, open("dest.bin", "wb") as dst:
    while True:
        chunk = src.read(CHUNK_SIZE)
        if not chunk:
            break
        dst.write(chunk)

print("Binary chunk copy finished successfully.")
Key Concept: Reading in fixed-size binary chunks handles arbitrarily large files without exhausting available RAM.

Exercise 26: Rename Multiple Files with Prefix
OS & File System

Practice Problem: Add a backup_ prefix to all .txt files in a target directory using pathlib.Path.

Automates batch file renaming across directories.
Given Input
Files: doc1.txt, doc2.txt
Expected Output
Renamed to backup_doc1.txt, backup_doc2.txt
Iterate with Path(".").glob("*.txt") and call file.rename(file.with_name(...)).
Python 3
from pathlib import Path

folder = Path(".")
for file in folder.glob("*.txt"):
    if not file.name.startswith("backup_"):
        new_name = file.with_name(f"backup_{file.name}")
        file.rename(new_name)
        print(f"Renamed: {file.name} -> {new_name.name}")
Key Concept: file.with_name() returns a new Path object with the updated filename while keeping the directory path intact.
