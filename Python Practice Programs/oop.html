class Student:
    def __init__(self, name, grades=None):
        self.name = name
        self.grades = grades if grades is not None else []

Given Input

Expected Output
Insufficient funds!
Withdrawal successful. Balance: 100.00
Check amount > self.balance before deducting money in withdraw().
Python 3
class BankAccount:
    def __init__(self, owner, balance=0.0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.balance += amount
            return True
        return False

    def withdraw(self, amount):
        if amount <= 0:
            print("Invalid withdrawal amount!")
            return False
        if amount > self.balance:
            print("Insufficient funds!")
            return False
        self.balance -= amount
        print(f"Withdrawal successful. Balance: {self.balance:.2f}")
        return True

acc = BankAccount("Bob", 500.0)
acc.withdraw(700.0)
acc.deposit(300.0)
acc.withdraw(700.0)
Key Concept: Validating inputs protects internal fields from entering invalid states (such as negative balances).

Exercise 30: Character Class with Auto Level-Up Logic
Encapsulation & Logic

Practice Problem: Build a game Character class with level = 1 and xp = 0. Add gain_xp(points) that automatically increments level every 100 XP.

Game state machines with automatic threshold level-ups.
Given Input
gain_xp(60), gain_xp(70)
Expected Output
Gained 60 XP.
Gained 70 XP.
Leveled Up! Level: 2 (XP: 30)
Use a while self.xp >= 100: loop, deducting 100 XP and adding 1 to level.
Python 3
class Character:
    def __init__(self, name):
        self.name = name
        self.level = 1
        self.xp = 0

    def gain_xp(self, points):
        self.xp += points
        print(f"{self.name} gained {points} XP.")
        while self.xp >= 100:
            self.xp -= 100
            self.level += 1
            print(f"🎉 Leveled Up! Now Level {self.level} (Excess XP: {self.xp})")

hero = Character("Aria")
hero.gain_xp(60)
hero.gain_xp(70)
Key Concept: A while loop ensures characters level up multiple times at once if they receive a large burst of XP.
Exercise 31: Playlist Class with Add, Remove & Shuffle
Classes & State

Practice Problem: Create a Playlist class with add_song(title), remove_song(title), and shuffle() using the random module.

Collection management combined with standard library utilities.
Given Input
Add ["Song A", "Song B", "Song C"], call shuffle()
Expected Output
Shuffled playlist with all original songs preserved
Use random.shuffle(self.songs) to randomize order in place.
Python 3
import random

class Playlist:
    def __init__(self, name):
        self.name = name
        self.songs = []

    def add_song(self, title):
        self.songs.append(title)

    def remove_song(self, title):
        if title in self.songs:
            self.songs.remove(title)

    def shuffle(self):
        random.shuffle(self.songs)

pl = Playlist("Coding Vibes")
pl.add_song("Song A")
pl.add_song("Song B")
pl.add_song("Song C")
print("Original:", pl.songs)

pl.shuffle()
print("Shuffled:", pl.songs)
Key Concept: random.shuffle() randomizes list order in place without requiring external data structures.
