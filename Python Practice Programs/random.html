Exercise 1: Generate 3 Random Integers
Random Sampling & Range

Practice Problem: Generate 3 random integers between 100 and 999 that are all exact multiples of 5.

Introduces random.randrange() with step parameters to restrict random candidates to numerical multiples.
Given Input
Range: [100, 999], Step: 5, Count: 3
Expected Output
Example: [145, 520, 895] (all divisible by 5)
Use random.randrange(100, 1000, 5) inside a loop or list comprehension.
Python 3
import random

# Generate 3 integers between 100 and 999 divisible by 5
random_multiples = [random.randrange(100, 1000, 5) for _ in range(3)]

print("3 random numbers divisible by 5:", random_multiples)
Key Concept: random.randrange(start, stop, step) generates numbers from start up to stop - 1 in increments of step without generating unwanted values first.
Exercise 2: Random Lottery Pick
Random Sampling & Range

Practice Problem: Create a lottery pool of 100 ticket numbers and pick 2 unique random winning tickets without replacement.

Applies random.sample() for non-repeating population draws.
Given Input
Tickets: 100 to 199, Winners: 2
Expected Output
Lucky winners: [142, 189] (guaranteed unique)
Use random.sample(population, k=2). Unlike random.choices(), sample() never duplicates items.
Python 3
import random

# Generate a pool of 100 ticket IDs
lottery_tickets = list(range(100, 200))

# Pick 2 unique winners without replacement
winners = random.sample(lottery_tickets, k=2)

print("Winning tickets:", winners)
Key Concept: random.sample() selects $k$ unique elements without replacement, raising ValueError if the requested sample size exceeds the population.

Practice Problem: Generate a cryptographically secure 6-digit One-Time Password (OTP) between 100000 and 999999 using Python's secrets module.

Uses CSPRNG (Cryptographically Secure Pseudo-Random Number Generator) for security-sensitive tokens.
Given Input
Range: [100000, 999999]
Expected Output
Secure OTP: 748192
Import secrets and call secrets.randbelow() or secrets.SystemRandom().randint(100000, 999999).
Python 3
import secrets

# Generate a cryptographically secure 6-digit number
otp = secrets.SystemRandom().randint(100000, 999999)

print(f"Secure OTP: {otp}")
Key Concept: Never use random.randint() for authentication tokens or passwords. The secrets module sources entropy from os.urandom(), making it resistant to prediction attacks.

Exercise 6: Generate Random Password
Strings & Cryptographic Secrets

Practice Problem: Generate a robust 12-character random password containing at least 1 uppercase letter, 1 digit, and 1 punctuation symbol.

Applies mandatory character guarantees followed by randomized shuffling with secrets.
Given Input
Length: 12, Requirements: [Upper, Digit, Symbol]
Expected Output
Example: 'mK9#xL2$vP7!' (satisfies all rules)
Pick 1 required character from each specific set first, fill remaining slots from the full pool, then shuffle the result.
Python 3
import secrets
import string

def generate_strong_password(length=12):
    # Ensure minimum guarantees
    password_chars = [
        secrets.choice(string.ascii_uppercase),
        secrets.choice(string.digits),
        secrets.choice(string.punctuation)
    ]
    
    # Fill remainder from combined character set
    full_pool = string.ascii_letters + string.digits + string.punctuation
    password_chars += [secrets.choice(full_pool) for _ in range(length - len(password_chars))]
    
    # Securely shuffle characters
    secrets.SystemRandom().shuffle(password_chars)
    return "".join(password_chars)

print("Generated Password:", generate_strong_password(12))
Key Concept: Guaranteeing mandatory character classes before shuffling prevents generating passwords that fail security validation.

Exercise 8: Generate Random Token and URL

Practice Problem: Generate a 32-byte secure hexadecimal authentication token and a URL-safe password-reset link using secrets.

Creates URL-safe tokens and cryptographic hex strings for web security workflows.
Given Input
Base URL: "https://example.com/reset?token="
Expected Output
Hex Token: 64-char string
Password Reset URL: https://example.com/reset?token=...
Use secrets.token_hex(32) and secrets.token_urlsafe(32).
Python 3
import secrets

# 32 bytes of entropy encoded as hex (64 hex characters)
auth_token = secrets.token_hex(32)

# URL-safe Base64 token for email reset links
url_token = secrets.token_urlsafe(32)
reset_url = f"https://example.com/reset?token={url_token}"

print("Auth Token (Hex):", auth_token)
print("Password Reset URL:", reset_url)
Key Concept: secrets.token_urlsafe() generates base64-encoded strings without characters like + or / that require special handling in URLs.
Exercise 9: Dice Roll Simulator
Tokens & Real-World Simulation

Practice Problem: Simulate rolling two standard 6-sided dice 5 times. Print the individual die values and their sum for each roll.

Applies repeated discrete uniform probability sampling.
Given Input
Die sides: [1, 6], Rolls: 5
Expected Output
Roll 1: (3, 5) -> Total: 8
...
In each iteration, roll d1 = random.randint(1, 6) and d2 = random.randint(1, 6).
Python 3
import random

for roll_num in range(1, 6):
    die1 = random.randint(1, 6)
    die2 = random.randint(1, 6)
    total = die1 + die2

Key Concept: Rolling two independent dice yields a triangular probability distribution (sums range from 2 to 12, with 7 having the highest probability).
Exercise 10: Generate Random Date
Tokens & Real-World Simulation

Practice Problem: Generate a random calendar date between January 1, 2020 and December 31, 2025 using datetime and random.randrange().

Combines date arithmetic (timedelta) with integer range sampling.
Given Input
Start: 2020-01-01, End: 2025-12-31
Expected Output
Random Date: YYYY-MM-DD (e.g., 2023-08-14)
Calculate days_between = (end_date - start_date).days and add timedelta(days=random.randrange(days_between)).
Python 3
import random
from datetime import date, timedelta

start_date = date(2020, 1, 1)
end_date = date(2025, 12, 31)

# Total days spanning the interval
time_delta_days = (end_date - start_date).days

# Pick a random day offset within the range
random_day_offset = random.randrange(time_delta_days + 1)
random_date = start_date + timedelta(days=random_day_offset)

print("Random Date:", random_date.strftime("%Y-%m-%d"))
Key Concept: Converting date intervals into total days allows uniform random day offsets to be added via datetime.timedelta(), properly accounting for leap years.
