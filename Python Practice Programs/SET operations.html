Exercise 27: Remove Duplicates (Preserving Order)
Advanced & Performance

Practice Problem: Remove duplicate items from a list while preserving their original order, using a set for fast lookup tracking.

Achieves $O(n)$ ordered deduplication using an auxiliary set.
Given Input
[4, 1, 2, 1, 3, 4, 5, 2]
Expected Output
[4, 1, 2, 3, 5]
Maintain a seen = set() and append to a result list only when item not in seen.
Python 3
raw_list = [4, 1, 2, 1, 3, 4, 5, 2]

seen = set()
ordered_unique = []

for item in raw_list:
    if item not in seen:
        seen.add(item)
        ordered_unique.append(item)

print("Ordered unique list:", ordered_unique)
Key Concept: item not in seen runs in $O(1)$ time, maintaining linear overall runtime while preserving insertion order.

Exercise 31: Membership Testing Performance
Advanced & Performance

Practice Problem: Write a benchmark comparison testing item in collection performance between a large list and a set.

Empirically verifies $O(1)$ set hash lookups versus $O(n)$ linear list scans.
Given Input
1,000,000 elements, target: -1 (worst case)
Expected Output
Set is orders of magnitude faster than list
Use time.perf_counter() around -1 in large_list vs -1 in large_set.
Python 3
import time

size = 1_000_000
test_list = list(range(size))
test_set = set(range(size))
target = -1  # Not present: triggers worst-case linear search

# Measure list lookup
start = time.perf_counter()
_ = target in test_list
list_duration = time.perf_counter() - start

# Measure set lookup
start = time.perf_counter()
_ = target in test_set
set_duration = time.perf_counter() - start

print(f"List lookup: {list_duration:.6f} s (O(n))")
print(f"Set lookup:  {set_duration:.6f} s (O(1))")
Key Concept: Set lookups use a hash table to jump directly to memory buckets in average $O(1)$ time, making them vastly faster than $O(n)$ list scans for large datasets.
