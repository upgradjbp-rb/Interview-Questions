Exercise 14: Memoization with lru_cache
Advanced Pipelines & Monads

Practice Problem: Optimize an exponential recursive Fibonacci function to run in $O(n)$ linear time using functools.lru_cache.

Caches pure function return values to eliminate redundant recursive calculations.
Given Input
fib(35)
Expected Output
Result: 9227465 (computed instantly)
Decorate the recursive function with @lru_cache(maxsize=None).
Python 3
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print("fib(35):", fib(35))
print("Cache statistics:", fib.cache_info())
Key Concept: lru_cache intercepts calls, returning precomputed answers for seen arguments instead of recomputing them.

Exercise 16: Pipeline Function
Advanced Pipelines & Monads

Practice Problem: Build a generalized pipeline(*funcs) function that feeds an initial value through an arbitrary sequence of functions from left to right.

Applies multi-stage transformations in left-to-right readable order.
Given Input
Initial: 5 → (add_2, triple, square)
Expected Output
Pipeline output: 441 ((5+2)*3)^2
Use reduce(): lambda initial: reduce(lambda acc, f: f(acc), funcs, initial).
Python 3
from functools import reduce

def pipeline(*funcs):
    return lambda initial: reduce(lambda acc, f: f(acc), funcs, initial)

add_2 = lambda x: x + 2
triple = lambda x: x * 3
square = lambda x: x ** 2

pipe = pipeline(add_2, triple, square)
print("Pipeline result:", pipe(5))  # (5 + 2) = 7 -> 7 * 3 = 21 -> 21^2 = 441
Key Concept: Unlike mathematical composition which reads right-to-left ($f(g(x))$), pipelines evaluate left-to-right, making data flows easier to follow.
Exercise 17: Transducer Pattern
Advanced Pipelines & Monads

Practice Problem: Implement a composable transducer step that maps and filters in a single pass without generating intermediate lists.

Combines map and filter transformations into a single iteration over the input sequence.
Given Input
[1, 2, 3, 4, 5, 6]
Expected Output
[8, 16, 24] (evens multiplied by 4)
Compose the reducer transformation so operations run sequentially on each element during the reduce loop.
Python 3
from functools import reduce

# Transducer helpers
def mapping(f):
    return lambda step: lambda acc, val: step(acc, f(val))

def filtering(predicate):
    return lambda step: lambda acc, val: step(acc, val) if predicate(val) else acc

# Base reducer that appends to list
append_step = lambda acc, val: acc + [val]

# Build transducer: filter evens, then multiply by 4
transduce = filtering(lambda x: x % 2 == 0)(mapping(lambda x: x * 4)(append_step))

data = [1, 2, 3, 4, 5, 6]
result = reduce(transduce, data, [])

print("Transduced output:", result)
Key Concept: Transducers decouple transformation logic from data structures, processing each item through the full pipeline in a single pass.
Exercise 18: Lazy Evaluation with Generators
Advanced Pipelines & Monads

Practice Problem: Create an infinite generator of even numbers and use itertools.islice to take only the first 5 elements lazily.

Streams infinite sequences on demand with zero memory overhead.
Given Input
Take 5 from infinite stream 2, 4, 6...
Expected Output
[0, 2, 4, 6, 8]
Use itertools.count(0, 2) or a while True: yield generator with itertools.islice().
Python 3
import itertools

def infinite_evens():
    n = 0
    while True:
        yield n
        n += 2

# Take the first 5 elements lazily without evaluating infinity
first_5 = list(itertools.islice(infinite_evens(), 5))
print("First 5 evens:", first_5)
Key Concept: Lazy evaluation defers computation until values are actually consumed, allowing you to model infinite sequences safely.

Exercise 20: Monadic Chaining (Maybe Monad)
Advanced Pipelines & Monads

Practice Problem: Implement a simple Maybe container class that wraps a value and supports chained .bind() calls, automatically short-circuiting on None.

Applies the Maybe Monad pattern to eliminate nested if x is not None defensive checks.
Given Input
Chain: 16 → sqrt → double → valid / none
Expected Output
Success: Maybe(8.0)
Failure: Maybe(None)
In .bind(func), return Maybe(None) if self.val is None, else Maybe(func(self.val)).
Python 3
import math

class Maybe:
    def __init__(self, value):
        self.value = value

    def bind(self, func):
        if self.value is None:
            return Maybe(None)
        try:
            return Maybe(func(self.value))
        except Exception:
            return Maybe(None)

    def __repr__(self):
        return f"Maybe({self.value})"

# Safe processing pipeline
safe_sqrt = lambda x: math.sqrt(x) if x >= 0 else None
double = lambda x: x * 2

result_valid = Maybe(16).bind(safe_sqrt).bind(double)
result_invalid = Maybe(-4).bind(safe_sqrt).bind(double)

print("Valid pipeline:", result_valid)
print("Invalid pipeline (handled cleanly):", result_invalid)
Key Concept: The Maybe monad wraps value access. If any step returns None or fails, subsequent pipeline steps are skipped safely without raising an exception.
