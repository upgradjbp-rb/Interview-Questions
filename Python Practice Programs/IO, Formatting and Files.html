scores = [85, 92, 78]
Expected Output
Name      Score
----------------
Alice     85

Use zip(names, scores) and format names using left-alignment: {name:<10}.
Python 3 
names = ["Alice", "Bob", "Charlie"]
scores = [85, 92, 78]

print("-" * 16)

# Parallel iteration

Key Concept: zip() pairs matching items, while :<10 pads strings to guarantee a consistent column width.

Python 3

Exercise 19. Write list of strings to a file
File Handling

Practice Problem: Take a list of fruits and persist each entry onto a new line in a file named fruits.txt.

Demonstrates disk persistence using write modes and context managers.
Given Input
["Apple", "Banana", "Cherry", "Date"]
Expected Output
File 'fruits.txt' created with 4 lines
Open the file with mode "w" and use f.writelines() or loop through each item adding \n.
Python 3 
fruit_list = ["Apple", "Banana", "Cherry", "Date"]

# Open file with 'w' mode (overwrites if already present)
with open("fruits.txt", "w") as f:
    for fruit in fruit_list:
        f.write(f"{fruit}\n")

print("File 'fruits.txt' has been created successfully.")
Key Concept: The with statement handles closing the file stream automatically, even if errors occur during writing.
Exercise 20. Count total lines in a file
File Handling

Practice Problem: Write a program that opens an existing text file and calculates exactly how many lines of text it contains.

Data auditing and memory-friendly file iteration on large files.
Given Input
File: sample.txt (12 lines)
Expected Output
The file contains 12 lines.
Iterate directly through the file object using a loop counter, or use sum(1 for _ in f).
Python 3 
# Efficient line-counting generator expression
with open("sample.txt", "r") as f:
    line_count = sum(1 for _ in f)

print(f"The file contains {line_count} lines.")
Key Concept: sum(1 for _ in f) counts lines in $O(1)$ memory without loading the whole file into RAM.

Exercise 22. Check if file is empty
File Handling

Practice Problem: Write a script that checks a file's metadata. If size is 0 bytes, print "File is empty"; otherwise, show its byte size.

Introduces OS-level file system metadata queries via os.stat or os.path.getsize.
Given Input
File: empty_log.txt (0 bytes)
Expected Output
Status: empty_log.txt is empty.
Use os.path.getsize(filename) or os.stat(filename).st_size after checking os.path.exists().
Python 3 
import os

filename = "empty_log.txt"

# Defensive verification: check existence first
if os.path.exists(filename):
    size = os.path.getsize(filename)
    if size == 0:
        print(f"Status: {filename} is empty.")
    else:
        print(f"Status: {filename} size is {size} bytes.")
else:
    print(f"File '{filename}' does not exist.")
Key Concept: os.path.getsize() directly inspects filesystem metadata without reading any file contents into memory.
Exercise 23. Delete a specific file
File Handling

Practice Problem: Write a program that asks for a filename, confirms deletion with the user, and removes it permanently.

Highlights high-risk system operations using defensive checks and user confirmation safeguards.
Given Input
File to delete: old_data.csv (confirmed with 'y')
Expected Output
File 'old_data.csv' has been deleted.
Check with os.path.exists(target), confirm input, and delete using os.remove(target).
Python 3 
import os

target = input("Enter filename to delete: ").strip()

if os.path.exists(target):
    confirm = input(f"Are you sure you want to delete '{target}'? (y/n): ")
    if confirm.lower() == 'y':
        os.remove(target)
        print(f"File '{target}' has been deleted.")
    else:
        print("Operation cancelled.")
else:
    print("Error: File does not exist.")
Key Concept: os.remove() bypasses the trash/recycle bin and deletes the target file immediately. Defensive guards prevent accidental data loss.
